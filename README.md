# Dynamic Strategy Game Engine

A versatile board game engine supporting "Connect-N" and Tic-Tac-Toe, featuring a rule-based AI opponent.

## Key Features
* **Strategic AI:** Implemented an AI agent using priority-based decision making (winning moves, blocking opponents, and center-control).
* **Scalable Board Logic:** Supports dynamic board sizes (up to 100x100) and configurable win conditions.
* **Matrix Algorithms:** Used optimized 2D array scanning to detect victory patterns across horizontal, vertical, and diagonal axes.
* **Robust UI:** Includes a comprehensive CLI with full input validation and error handling.

## Tech Stack
* **Language:** Python 3
* **Concepts:** Matrix Manipulation, AI Logic, Procedural Programming.
